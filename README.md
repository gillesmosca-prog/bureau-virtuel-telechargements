# Télécharger Bureau virtuel

Version 0.18.0 — pour Windows et pour Mac. Aucun compte GitHub n’est nécessaire.

| Ton ordinateur | Fichier à télécharger |
| --- | --- |
| **Windows 10 ou 11** (x64) | **[Bureau-virtuel-0.18.0-Windows-x64-Setup.exe](https://github.com/gillesmosca-prog/bureau-virtuel-telechargements/releases/download/v0.18.0/Bureau-virtuel-0.18.0-Windows-x64-Setup.exe)** |
| **Mac à puce Apple** (M1 et ultérieures) | **[Bureau-virtuel-0.18.0-macOS-arm64.dmg](https://github.com/gillesmosca-prog/bureau-virtuel-telechargements/releases/download/v0.18.0/Bureau-virtuel-0.18.0-macOS-arm64.dmg)** |
| **Mac à processeur Intel** | **[Bureau-virtuel-0.18.0-macOS-x64.dmg](https://github.com/gillesmosca-prog/bureau-virtuel-telechargements/releases/download/v0.18.0/Bureau-virtuel-0.18.0-macOS-x64.dmg)** |

Pour savoir quel Mac tu as : menu Pomme → **À propos de ce Mac**. La ligne **Puce** ou **Processeur** indique « Apple » ou « Intel ».

Si un lien t’amène sur la [page de la version](https://github.com/gillesmosca-prog/bureau-virtuel-telechargements/releases/tag/v0.18.0), ouvre **Assets** et clique sur le fichier de ton ordinateur.

## Installer sur Windows

1. Clique sur le lien **Windows** ci-dessus.
2. Dans ton navigateur, appuie sur **Ctrl + J** pour retrouver le fichier téléchargé.
3. Ouvre le fichier `.exe` et suis l’assistant d’installation. Tu trouveras ensuite **Bureau virtuel** dans le menu Démarrer.

Si une version précédente est installée, relance simplement le nouvel installateur : tes données sont conservées.

## Installer sur Mac

macOS 13.5 ou ultérieur est requis.

1. Clique sur le lien **Mac** qui correspond à ton ordinateur, puis ouvre le fichier `.dmg` depuis tes téléchargements.
2. Dans la fenêtre qui s’ouvre, glisse **Bureau virtuel** sur le dossier **Applications**.
3. Ouvre **Applications** et double-clique sur **Bureau virtuel**.
4. Au premier lancement, macOS indique qu’il ne peut pas vérifier l’application : elle n’est pas signée avec un certificat Apple payant. Clique sur **Terminé**, ouvre **Réglages Système → Confidentialité et sécurité**, descends jusqu’au message sur Bureau virtuel, clique sur **Ouvrir quand même** et confirme avec ton mot de passe ou Touch ID. Cette autorisation n’est demandée qu’une fois. Ne désactive aucune protection de macOS.
5. Le bureau s’ouvre dans ton navigateur. Une fenêtre propose de **connecter ton abonnement ChatGPT**.

Le bureau continue de fonctionner en arrière-plan, sans icône dans le Dock. **Rouvre l’application** pour afficher son menu : ouvrir le bureau, connecter ChatGPT, accès distant, guide d’utilisation et **Arrêter Bureau virtuel**.

Tes données restent sur ton Mac, dans `~/Library/Application Support/BureauVirtuel`. Elles sont conservées quand tu mets à jour ou supprimes l’application.

## Vérifier un téléchargement

Le fichier `SHA256SUMS.txt` de la [page de la version](https://github.com/gillesmosca-prog/bureau-virtuel-telechargements/releases/tag/v0.18.0) donne l’empreinte de chaque fichier.

Les archives **Source code** contiennent les fichiers de cette page de téléchargement, pas l’application. La version précédente pour Windows reste disponible : [0.16.0](https://github.com/gillesmosca-prog/bureau-virtuel-telechargements/releases/tag/v0.16.0).
