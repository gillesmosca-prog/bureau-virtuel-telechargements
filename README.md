# Télécharger Bureau virtuel pour Windows

**[Télécharger l’installateur Bureau virtuel 0.16.0 (.exe)](https://github.com/gillesmosca-prog/bureau-virtuel-telechargements/releases/download/v0.16.0/Bureau-virtuel-0.16.0-Windows-x64-Setup.exe)**

Pour Windows 10 et 11 x64. Aucun compte GitHub n’est nécessaire.

1. Clique sur le lien ci-dessus. Si tu arrives sur la [page de la version](https://github.com/gillesmosca-prog/bureau-virtuel-telechargements/releases/tag/v0.16.0), ouvre **Assets** et clique sur `Bureau-virtuel-0.16.0-Windows-x64-Setup.exe`.
2. Dans ton navigateur, appuie sur **Ctrl + J** pour retrouver le fichier téléchargé. Clique sur **Afficher dans le dossier** si tu veux voir où il a été enregistré.
3. Ouvre le fichier `.exe` et suis l’assistant d’installation. Tu trouveras ensuite **Bureau virtuel** dans le menu Démarrer.

Les archives **Source code** contiennent les fichiers de cette page de téléchargement. Choisis le fichier `.exe` pour installer Bureau virtuel.
